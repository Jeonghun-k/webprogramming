## 5️⃣ 자바스크립트 객체 종류
- **자바스크립트는 객체 기반 언어**
  - 초기엔 지향 언어가 아니었으나, 현재는 객체 지향 언어처럼 사용됨
- **객체 유형**
  1. 코어 객체 (Array, Date, String, Math 등)
  2. HTML DOM 객체
  3. 브라우저 객체
- **객체 생성 및 접근**
  - `new` 키워드로 생성
  - `객체.멤버`로 접근

---

## 6️⃣ 자바스크립트 배열
1. 대괄호 `[]`로 생성 가능
2. 만드는 방법
   - `[]` : 초기화하면서 생성
   - `new Array()` : `Array` 객체로 생성  
     → 예: `new Array(7)` → 크기 7의 배열
3. `.length` 기본 제공 (가변 길이)
4. 특징
   - `[]`로 만들어도 내부적으로 `Array` 객체로 처리됨
   - 여러 타입의 데이터 혼합 가능
5. 주요 메소드
   - `concat()` : 배열 결합
   - `join()` : 배열을 문자열로 연결
   - `reverse()` : 배열 반전
   - `slice()` : 새로운 배열 생성
   - `sort()` : 정렬 (원본 변경)

---

## 7️⃣ Date 객체
1. 시간 정보를 담는 객체
2. 생성: `new Date()`
3. 주요 메소드
   - `.getDate()` : 일 반환
   - `.getHours()` : 시 반환
   - `.getMonth()` : 월 반환 (0~11)

---

## 8️⃣ String 객체
1. 문자열을 담는 객체
2. 생성 후 수정 불가 (immutable)
3. 생성 예시
   ```js
   let hello0 = new String("Hello");
   let hello1 = new String("Hello");
   let hello2 = "Hello";
   let hello3 = "Hello";
   ```
4. 메소드 예시
   - `trim()` : 공백 제거
   - `concat()` : 문자열 결합
   - `indexOf()` : 인덱스 찾기

---

## 9️⃣ Math 객체
1. 대문자로 시작 → **Static 메소드 제공**
2. 수학 계산 관련 프로퍼티 및 메소드 제공
3. `new Math()` 없이 사용 가능
4. 주요 메소드
   - `random()` : 0~1 사이 난수 반환
   - `floor(m)` : 내림
5. **경고창 종류 외워두기**

---

## 🔟 사용자 객체 만들기
1. **new Object()로 생성**
   ```js
   let obj = new Object();
   obj.name = "홍길동";
   obj.sayHi = function() { alert("안녕!"); };
   ```
2. **리터럴 표기법**
   ```js
   let abc = {
       name: "정훈",
       age: 24,
       greet: function() { console.log("Bonjour!"); }
   };
   ```
3. **프로토타입**
   - 객체의 모양을 가진 **틀**
   - 예시:
     ```js
     function Student(name) {
         this.name = name;
     }
     ```
