## CH08. HTML DOM과 Document

### 1. 페이지와 자바스크립트 객체

1.  브라우저 안에는 **DOM**, **코어 객체**, **BOM 객체**가 포함되어
    있다.
2.  **코어 객체**: 자바스크립트에서 직접 만들어 사용하는 객체.
3.  **BOM (Browser Object Model)**: 브라우저 관련 객체 집합 (BOM 안에
    DOM 포함).
4.  **DOM (Document Object Model)**: HTML 문서를 트리 형태로 표현한
    구조.

------------------------------------------------------------------------

### 2. HTML DOM

1.  **돔 트리(DOM Tree)**로 이루어져 있으며, 웹페이지의 각 HTML 태그마다
    객체 생성.
2.  **DOM 트리 구조**
    -   HTML 태그의 포함 관계에 따라 부모-자식 관계로 트리 생성.
3.  **DOM 객체**
    -   DOM 트리의 한 노드이며, 각 HTML 태그에 대응되는 객체.
    -   "DOM 노드", "DOM 엘리먼트"라고도 부름.
4.  **DOM 트리의 특징**
    -   루트는 항상 `document` 객체.
    -   HTML 태그 종류만큼 객체가 생성됨.
5.  **브라우저의 렌더링 과정**
    1.  DOM 트리 틀 생성
    2.  DOM 객체 생성
    3.  브라우저가 객체를 화면에 출력
    4.  로딩 완료 시 DOM 트리 완성
    5.  객체 변경 시 화면이 즉시 갱신됨.
6.  **HTML 요소(Element)**
    -   태그 + 콘텐츠 = 하나의 노드
    -   구성 요소: 이름, 속성, CSS 스타일, 이벤트 리스너, 콘텐츠
7.  **DOM 객체의 구성 요소**
    -   **프로퍼티**: HTML 태그의 속성을 반영\
    -   **메서드**: DOM 제어용 멤버 함수\
    -   **컬렉션**: 자식 DOM 객체들의 주소 저장\
    -   **이벤트 리스너**: 이벤트 발생 시 동작 정의\
    -   **CSS 스타일**: 스타일 속성

------------------------------------------------------------------------

### 3. DOM 객체 다루기

-   특정 객체 구분: `id` 속성 사용\
    예: `<p id="firstP">안녕하세요</p>`\
-   DOM 객체 찾기: `document.getElementById()`\
-   DOM 객체의 CSS3 스타일 동적 변경 가능

------------------------------------------------------------------------

### 4. innerHTML 프로퍼티

-   시작 태그와 종료 태그 사이의 **HTML 콘텐츠**를 의미.

------------------------------------------------------------------------

### 5. this

-   `this`: **객체 자신**을 가리키는 키워드.
-   `obj`: 자바의 `Object` 클래스처럼 **최상위 객체**를 의미.

------------------------------------------------------------------------

### 6. document 객체

1.  **document**
    -   문서 전체를 대표하는 객체.
    -   프로퍼티: 문서의 전반적인 속성 포함\
    -   메서드: DOM 검색, 생성, 제어 담당
    -   DOM 접근의 시작점이자 최상위 객체
2.  **접근 방법**
    -   `window.document` 또는 `document`
    -   `document` 객체는 DOM 객체가 아님.

------------------------------------------------------------------------

### 7. DOM 트리에서 객체 찾기

-   태그 이름 또는 `class` 속성으로 검색 가능.

------------------------------------------------------------------------

### 8. document.write() / writeln()

#### 로딩 과정

1.  페이지 로드 전 빈 document 생성\
2.  브라우저가 HTML을 위→아래로 해석하며 DOM 객체 생성\
3.  `</html>` 태그를 만나면 document 완성 및 닫힘

#### 메서드

-   `write()`: document 끝에 HTML 콘텐츠 추가\
-   `writeln()`: `\n` 추가하여 줄바꿈 효과

------------------------------------------------------------------------

### 9. document.open() / close()

-   `open()`: 기존 DOM 트리를 삭제하고 새로 시작\
-   `close()`: HTML 페이지를 완성하고 더 이상 `write()` 불가능

------------------------------------------------------------------------

### 10. 문서의 동적 구성

-   **DOM 객체 생성**: `document.createElement("태그이름")`\
-   **DOM 트리에 삽입**
    -   `부모.appendChild(객체)`
    -   `부모.insertBefore(객체, 기준자식)`
-   **DOM 객체 삭제**
    -   `부모.removeChild(자식객체)`

------------------------------------------------------------------------

## CH09. 이벤트 처리

### 1. 이벤트

-   클릭, 키보드 입력 등 사용자 상호작용을 의미.

### 2. 이벤트 리스너

-   이벤트 발생 시 실행되는 자바스크립트 코드.

### 3. 이벤트 종류

-   리스너 이름은 **이벤트명 앞에 `on`**을 붙임.\
    예: `onmousedown` → `mousedown` 이벤트의 리스너

------------------------------------------------------------------------

### 4. 리스너 작성 방식 (⚠️ 시험 자주 출제)

1.  **HTML 태그 내 작성**

2.  **리스너 프로퍼티에 작성**

    ``` js
    element.onclick = functionName;
    ```

3.  **addEventListener() 메서드 사용**

    ``` js
    p.addEventListener("mouseover", over);
    ```

    -   이벤트 흐름: **캡처 → 버블**

4.  **익명 함수로 작성**

    ``` js
    p.onmouseover = function() { this.style.backgroundColor = "orchid"; };
    ```

------------------------------------------------------------------------

### 5. 이벤트 객체

-   이벤트 발생 시 브라우저가 자동 생성하여 리스너의 첫 번째 매개변수로
    전달됨.

    ``` js
    function f(e) { ... }
    obj.onclick = f;
    ```

### 6. 이벤트 객체의 주요 프로퍼티

-   `target`: 이벤트가 발생한 객체 정보 포함.

------------------------------------------------------------------------

### 7. 이벤트의 기본 행동 취소

-   HTML 태그의 디폴트 행동을 막는 방법:
    1.  리스너에서 `false` 반환
    2.  이벤트 객체의 `preventDefault()` 호출

------------------------------------------------------------------------

### 8. 이벤트 흐름 (⚡ 캡처와 버블 꼭 암기)

1.  이벤트 발생 → 객체 도달 → DOM 트리 타고 전파\
2.  **캡처 단계**: 위에서 아래로 탐색\
3.  **버블 단계**: 아래에서 위로 전파

------------------------------------------------------------------------

### 9. 이벤트 흐름 중단

-   `stopPropagation()` 호출 시 중단 가능.

------------------------------------------------------------------------

### 10. 마우스 이벤트

-   다양한 마우스 관련 이벤트 존재 (`onclick`, `onmousemove`,
    `oncontextmenu` 등).

------------------------------------------------------------------------

### 11. oncontextmenu

-   마우스 오른쪽 버튼 클릭 시 발생.\
-   기본적으로 컨텍스트 메뉴를 표시하지만, 리스너에서 이를 제어 가능.

------------------------------------------------------------------------

### 12. onload

-   **window 객체**에 발생.\
-   웹페이지 로딩 완료 시 자동 실행되는 리스너.

### 13. 이미지 로딩 완료 이벤트

-   이미지 객체에서 `onload` 발생 시 이미지 로딩 완료 의미.

------------------------------------------------------------------------

### 14. onblur / onfocus

-   `onfocus`: 포커스 획득 시\
-   `onblur`: 포커스 해제 시

------------------------------------------------------------------------

### 15. 라디오버튼 & 체크박스

-   라디오버튼: `<input type="radio">`
-   체크박스: `<input type="checkbox">`

------------------------------------------------------------------------

### 16. select 객체와 onchange

-   `<select>`로 만든 콤보박스에 적용되는 이벤트.

------------------------------------------------------------------------

### 17. 키보드 이벤트

-   `onkeydown`: 키 눌릴 때\
-   `onkeypress`: 엔터, 스페이스, ESC 등 특정 키만\
-   `onkeyup`: 키가 떼어질 때

------------------------------------------------------------------------

### 18. onreset / onsubmit

-   `onreset`: 초기화 버튼 클릭 시 발생
    -   `false` 반환 시 초기화되지 않음\
-   `onsubmit`: 전송 버튼 클릭 시 발생
    -   `false` 반환 시 전송되지 않음

------------------------------------------------------------------------

> 📚 **요약:**\
> DOM은 문서의 구조를 트리 형태로 표현한 모델이며,\
> 이벤트는 사용자와의 상호작용을 처리하는 핵심 메커니즘이다.\
> `addEventListener()`, 캡처/버블 단계, `preventDefault()`는 시험
> 포인트!
