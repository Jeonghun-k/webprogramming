# 자바스크립트 기본 정리

## 1. 자바스크립트 언어

-   사용자의 입력 및 계산
    -   마우스, 키보드 입력은 자바스크립트로만 가능
-   웹페이지 내용 및 모양의 동적 제어
-   브라우저 제어
-   웹서버와의 통신
-   웹 애플리케이션 작성

## 2. 자바스크립트 코드 위치

-   HTML 태그의 리스너 속성에 작성
-   `<script>` 태그에 작성
-   스크립트 파일에 작성
-   URL 부분에 작성

## 3. 리스너 속성에 코드 작성

``` html
onmouseover="this.src='media/banana.png'"
```

## 4. `<script>` 태그

-   head나 body 내 어디든 가능
-   예시:

``` javascript
function over(obj){
    // 코드 작성
}
```

## 5. 자바스크립트 코드를 별도 파일에 저장

-   여러 웹페이지에서 불러오기 가능
-   `<script>` 태그의 `src` 속성을 이용
-   HTML5부터 `src` 속성에 코드 추가 작성 불가
-   `a href="javascript:alert('클릭하셨나요?')"` 형태 가능
-   `alert("")` → 경고창 출력
-   HTML 콘텐츠 출력: `document.write()`
-   줄바꿈: `\n`
-   입력창: `prompt("메세지", "디폴트값")`
-   확인/취소 다이얼로그: `confirm("메세지")`

## 6. 식별자

-   변수, 상수, 함수 이름
-   규칙
    -   첫 문자: 알파벳, 언더바(\_), \$ 가능
    -   두 번째 이상: 알파벳, \_, 숫자, \$ 가능
    -   대소문자 구분
    -   예약어 사용 불가

## 7. 문장

-   세미콜론 사용 (생략 가능)

## 8. 데이터 타입

-   숫자 (정수, 실수)
-   논리값: true / false
-   문자열
-   객체 레퍼런스 (C 포인터 유사)
-   null (값 없음, Null과 다름)
-   문자 타입 없음 → 문자열로 표현

## 9. 변수

-   데이터 저장 공간
-   선언 방식
    -   var / let / const / 타입 선언 없이 사용 가능
-   타입 없음 (int age; 불가능)

## 10. 변수의 범위

-   전역 변수: 함수 밖에서 선언
-   지역 변수: 함수 내 `let`
-   블록 변수: if, while, for 내부 `let`
-   this로 전역변수 접근 가능

예시:

``` javascript
var x;
function f(){
    var x;
    x = 1;
    this.x = 100;
}
```

## 11. 상수

-   const로 선언 (수정 불가)

## 12. 리터럴

-   데이터 값 자체

## 13. 문자열 리터럴

-   "" 와 '' 모두 사용 가능

## 14. 연산자 우선순위

-   괄호 \> 증감/not \> 곱셈/나눗셈/나머지 \> 덧셈/뺄셈 \> 비교 \> and
    \> or \> 대입
-   산술: \*, /, %, +, -
-   시프트: \<\<, \>\>, \>\>\>
-   비교: \<, \<=, \>, \>=, ==, !=
-   비트: &, \^, \|
-   할당: =

예시:

``` javascript
a = 1
++a + ++a + ++a  // 결과: 9

a = 1
a++ + a++ + a++  // 결과: 6
```
